# Experiment 017：7B 最终对照审查

16/16 次运行完成，四个 seed（121–124）与校准/容量 seed 分离，四策略循环顺序。云端结果已下载，本地重新运行汇总，统计与云端一致。请求日程与 payload 身份、模型身份和运行标识检查通过，控制错误为零；所有运行终态通过服务健康检查，后台已清理。

Canary 减 binary 的 goodput 均值为 -0.17447 req/s，四 seed 配对 Student-t 95% 区间 [-0.27319, -0.07575]。满容量恢复平均延迟：binary 28.83 秒、canary 70.79 秒，即多约 41.96 秒。两类恢复在四个 seed 均到达终点。

全部运行的模型重启数为零。两个负载均选择 mbt1024，切换仅更新准入策略；但当前执行器仍先暂停准入并排空，因此升容步骤更多的 canary 产生更多 503。模型不重启不等于准入切换没有停顿。

固定高准入策略取得更高 goodput，同时保留更多完成但超时请求。Oracle 预知边界但受同一策略目录与执行器约束，不能视为所有策略的数学 goodput 上界。当前结果支持跨同系列模型规模的控制机制运行和正常路径成本测量，故障收益仍待专门的 7B 实验。
